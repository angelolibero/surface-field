# Architecture

`src/SurfaceField.tsx` owns the two canvases and chooses which thread draws. `src/engine.ts` is the renderer: cell layout, drawing, pointer light, rings, resizing and the animation schedule, with no DOM access; everything it needs from the page arrives through an environment object. `src/dom.ts` supplies that environment on the main thread: colour and box reads and the window listeners. With the `worker` prop, `src/worker-client.ts` queues the same calls and posts them once per frame to `src/field.worker.ts`, where `src/worker-runtime.ts` replays them into the same engine on an OffscreenCanvas. The renderer retains its original draw math and constants. `src/controller.ts` is an instance-owned signal channel. It stores only the latest committed scene so a field mounted after its layout producer can paint immediately. Pointer footprints and previews are transient. `src/index.ts` limits the public exports.

The renderer is one closure per effect run, sharing cell buffers, dirty regions and frame scheduling; `startSurfaceField` returns its handlers and nothing else. It is private: `src/index.ts` does not export it, and the package boundary does not require exposing these internals.

The field measures CSS rectangles at its boundary and scales its canvas up to device pixels, capped at device pixel ratio 2. When connected lines are enabled, their fabric canvas is behind the dot canvas. Four seconds after its last paint a resting field gives back the buffers the browser cached while it was drawing: each canvas is copied into a scratch canvas, resized one pixel and back, and copied back, so the picture is the same bit for bit and only one texture per canvas remains. The outer element clips both canvases, stays hidden from accessibility, and lets pointer input reach the content above it.

The renderer can subscribe to window pointer events while mounted so a held press can end outside the field. Press ownership is limited by `interactionRoot` and the field bounds. The instance controller limits host scene and gesture messages to one field. Theme changes on arbitrary host ancestors are supplied through `refreshTheme()`, leaving host theme conventions outside this package.

The module is safe to import during server rendering. Browser objects are read after the component mounts. An effect cleanup removes its controller subscription, event listeners, observers, animation frames and timers. Host event bridges are outside this package.
