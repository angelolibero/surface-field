# Architecture

`src/SurfaceField.tsx` owns the two canvases and chooses which thread draws. `src/engine.ts` is the renderer: cell layout, drawing, pointer light, rings, resizing and the animation schedule, with no DOM access; everything it needs from the page arrives through an environment object. `src/dom.ts` supplies that environment on the main thread: colour and box reads and the window listeners. With the `worker` prop, `src/worker-client.ts` queues the same calls and posts them once per frame to `src/field.worker.ts`, where `src/worker-runtime.ts` replays them into the same engine on an OffscreenCanvas. The renderer retains its original draw math and constants. `src/controller.ts` is an instance-owned signal channel. It stores only the latest committed scene so a field mounted after its layout producer can paint immediately. Pointer footprints and previews are transient. `src/index.ts` limits the public exports.

The renderer is one closure per effect run, sharing cell buffers, dirty regions and frame scheduling; `startSurfaceField` returns its handlers and nothing else. It is private: `src/index.ts` does not export it, and the package boundary does not require exposing these internals.

The field measures CSS rectangles at its boundary and scales its canvas up to device pixels, capped at device pixel ratio 2. When connected lines are enabled, their fabric canvas is behind the dot canvas.

The renderer repaints only the cells that change, so it depends on a canvas keeping what was drawn before. A canvas on screen does not always keep it: on the worker path the browser hands each frame to the compositor and copies it into the next buffer, and that copy can fail, leaving a black buffer in which only the repainted cells come back. So each layer draws on a retained canvas of its own, an OffscreenCanvas that never reaches the compositor, and every painted frame presents it to the visible canvas with one same-size `copy` draw. The picture is the one the incremental drawing produced, byte for byte (`scripts/paint-parity/` proves it), and a visible buffer that loses its content is whole again at the next frame. The cost is one full-canvas copy per painted frame and one extra backing per layer; a field at rest presents nothing. Where OffscreenCanvas does not exist, the renderer draws on the visible canvas directly.

Four seconds after its last paint a resting field gives back the buffers the browser cached while it was drawing: each visible canvas is resized one pixel and back, and the retained picture is presented again, so nothing on screen moves and only one texture per visible canvas remains.

Setting `globalThis.SURFACE_FIELD_TRACE = true` on the thread the renderer runs in (the worker's own global on the worker path) logs one `console.debug` line per event that can change what a canvas holds: start, resize, full paint, trim, sleep, wake, a lost or restored context, a repair, dispose. It is meant for diagnosing drawing faults and costs one property read per event when off. The outer element clips both canvases, stays hidden from accessibility, and lets pointer input reach the content above it.

The renderer can subscribe to window pointer events while mounted so a held press can end outside the field. Press ownership is limited by `interactionRoot` and the field bounds. The instance controller limits host scene and gesture messages to one field. Theme changes on arbitrary host ancestors are supplied through `refreshTheme()`, leaving host theme conventions outside this package.

The module is safe to import during server rendering. Browser objects are read after the component mounts. An effect cleanup removes its controller subscription, event listeners, observers, animation frames and timers. Host event bridges are outside this package.
